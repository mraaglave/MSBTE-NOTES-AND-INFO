# ✅ PRE-PUBLISH CHECKLIST

Whenever you are about to finalize a new blog post, news update, or any content page for MSBTE Notes & Info, you MUST go through this checklist and verify each item.

## 🔍 SEO & Metadata
- [ ] **Title Tag**: `<title>` contains the primary keyword and is under 60 characters.
- [ ] **Meta Description**: Between 140–155 characters, includes the primary keyword and a clear benefit.
- [ ] **Canonical URL**: Check that the canonical URL is correct and matches the live URL.
- [ ] **OG Image**: Ensure an Open Graph image is uploaded and correctly referenced in the meta tags.
- [ ] **SEO Validation**: Perform a final pass on all SEO-related tags and headers.

## 🛠️ Structured Data (Schema)
- [ ] **Article Schema**: JSON-LD Article schema must be present in the `<head>`.
- [ ] **FAQ Schema**: JSON-LD FAQ schema must be in the `<head>` and correspond to visible `<details>` elements on the page.
- [ ] **Important Schema Check**: Verify all other relevant structured data (e.g., BreadcrumbList, Website).

## 📝 Content & Structure
- [ ] **H1 Heading**: Must exist and contain the primary keyword.
- [ ] **H2/H3 Subheadings**: Use secondary keywords naturally throughout the content.
- [ ] **Internal Linking**: Include at least 3 internal links to other relevant pages on MSBTE Notes & Info.
- [ ] **Table of Contents**: Ensure jump links are functional and appear in mobile search results where applicable.
- [ ] **Grammar & Spelling**: Perform a comprehensive grammar check.

## 🚀 Site Integration
- [ ] **Sitemap Update**: Add the new page URL to `sitemap.xml`.
- [ ] **Data JSONs**: Register the page in `Blog/blogs.json` or `News/news.json`.
- [ ] **Visual Verification**: Check breadcrumbs and overall layout in the browser.

## 🎨 Theme & Layout
- [ ] **Theme Consistency**: Maintain the established theme and template of the MSBTE Notes & Info site.
- [ ] **Structural Optimization**: Adjust layout or structure as needed for the specific page content while following site standards.
