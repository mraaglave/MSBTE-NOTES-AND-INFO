Micro-Project Ideas

1. 4-Bit Binary Adder/Subtractor

Design and build a circuit that can perform both addition and subtraction on two 4-bit binary numbers using full adders and XOR gates.

2. Digital Clock using Counters

Create a simple digital clock (HH:MM:SS) using asynchronous or synchronous counters (like IC 7490/7493) and 7-segment displays (with IC 7447 decoders).

3. Traffic Light Controller

Design a sequential logic circuit to control a simple traffic light sequence (Red, Yellow, Green) for a single intersection using timers (like IC 555) and flip-flops.

4. Digital Dice Roller

Build a circuit that simulates rolling a dice, displaying a random number from 1 to 6 on a 7-segment display using counters and logic gates.

5. BCD to Excess-3 Code Converter

Implement a combinational logic circuit that converts a 4-bit Binary Coded Decimal (BCD) input into its corresponding Excess-3 code output.
